# Engine v0.4 — Visual Fidelity Specification

Stable gameplay baseline: v0.3.

The v0.4 milestone introduces a higher-quality top-down rendering language while retaining the same racing-line, physics, ghost, surface and track-builder systems.

Visual target: highly readable premium top-down presentation inspired by the production quality of classic planning racers, but with entirely original Fjord Games art direction and assets.


## v0.5 benchmark note
This branch intentionally keeps all production assets original while using the classic top-down line-drawing racing experience as a responsiveness, readability, pacing, and presentation benchmark.
