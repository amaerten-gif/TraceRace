# Trace Race HD - Graphics Pass 1

Built from the confirmed-working Production 0.1.4 branch.

Changes in this pass are deliberately visual only:
- Original high-detail top-down blue car sprite generated for Trace Race.
- Transparent sprite integrated at runtime with a procedural fallback.
- Improved asphalt detail and broken centre markings.
- Denser visual road wear while preserving racing-line readability.
- Existing physics, drawing, ghost, surface and track-builder systems retained.

Open `project.godot` in Godot 4.2+ and run the project.
